# First Website

This repository contains my first web development project. It was created for educational purposes to practice layout skills and client-side scripting.

## Project Description

The website is a static web page with integrated interactive elements. During development, the main focus was on learning basic syntax and web document structure.

## Technologies Used

*   **HTML5** — page structure and markup.
*   **CSS3** — styling, element design, and basic layout.
*   **JavaScript** — adding interactivity (event handling, DOM manipulation, or simple scripts).

## Features

*   Basic page structure (header, main content, footer).
*   Element styling via CSS (colors, fonts, margins).
*   Integration and execution of simple JavaScript scripts.

## How to Run

Since the project consists of static files, no server-side setup or bundlers are required.
1. Download the project files.
2. Open the `index.html` file in any modern browser.

## Project Status

The project is completed as part of an educational assignment. Further improvements to functionality and design are possible in the future.
